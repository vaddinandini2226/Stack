# Stack Data Structure using Linked List (Java)

## Overview
This repository contains Java implementations of the **Stack** data structure using a **Singly Linked List**. The programs demonstrate the fundamental operations of a stack while following the **LIFO (Last In, First Out)** principle.

## Branch
**dev**

## Programs Included

### 1. Stack Push and Display
This program demonstrates:
- Creating a stack using a linked list.
- Inserting elements using the `push()` operation.
- Displaying the stack from top to bottom using the `print()` method.

**Operations Covered**
- `push(int data)`
- `print()`

### 2. Stack Operations
This program extends the basic implementation by supporting additional stack operations.

**Operations Covered**
- `push(int data)` – Inserts an element onto the stack.
- `peek()` – Returns the top element without removing it.
- `pop()` – Removes and returns the top element.
- `size()` – Returns the number of elements in the stack.
- `print()` – Displays all elements in the stack.

## Data Structure Used
- Singly Linked List

## Stack Principle
**LIFO (Last In, First Out)**

Example:
```
Push: 70
Push: 30
Push: 56

Stack:
56
30
70

Peek: 56

Pop Order:
56
30
70
```

| Operation | Complexity |
